# Probability_Analysis_food_delivery_time
This is prediction analysis of food delivery time based on influencing factors such weather, time of the day, traffic conditions and  distance.
# The goal is to determine probability distribution and their meaning.
## Tools Used
- **Environment:** Kaggle Notebooks
- **Language:** Python (`pandas`, `numpy`, `seaborn`, `matplotlib`)
- **Version Control:** GitHub

## Dataset
- **Source:** [Kaggle - Food Delivery Time Prediction](https://www.kaggle.com/datasets/denkuznetz/food-delivery-time-prediction)
