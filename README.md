
# Probability Analysis

A collection of probability analysis projects. Each project folder has the same structure: `data/` (raw, untouched), `analysis/` (cleaning and calculations), `outputs/` (charts and tables).

| Project                                    | Question                                                          | Tools                    |
| ------------------------------------------ | ----------------------------------------------------------------- | ------------------------ |
| [food_delivery](food_delivery_time/)             | Probability analysis of food delivery times                       | Jupyter Notebook, Python |
| [certified_livestock](certified_organic_livestock/) | Probability analysis of certified organic livestock, 2008 vs 2011 | Google Sheets            |
